Student Examination Fee Calculator
# About the Project

This is a beginner-level Python project developed as part of my Python learning journey. It is inspired by a practical task in the Students Affairs Department: calculating examination fees submitted by students.

The program accepts fee amounts, calculates the running total, and displays the final amount collected when the user chooses to quit.

# Features

Accepts examination fee amounts through user input.

Calculates the running total of fees collected.

Uses a loop to process multiple submissions.

Allows the user to exit by entering q.

Displays the final total of fees collected.

Python Concepts Practiced

Variables and data types

input() and type conversion

while loops

if-else conditions

break statements

Basic error handling

# How to Run

Install Python 3.

Download or clone this repository.

Open a terminal in the project folder.

# Run:

python 01_exam_fee_calculator.py

Enter a fee amount when prompted.

Enter q to stop and display the final total.

# Example

Enter fees submitted by students (or q to quit): 1200
The fees submitted so far: 1200

Enter fees submitted by students (or q to quit): 1500
The fees submitted so far: 2700

Enter fees submitted by students (or q to quit): q
Final fees collected: 2700
No more submission
